# ตลาดนัดออนไลน์ อำเภอชาติตระการ

หน้าเว็บแสดงร้านค้าท้องถิ่น พร้อมระบบจัดการ (Admin) แบบง่าย ๆ

## ไฟล์ในโปรเจกต์

| ไฟล์ | คำอธิบาย |
|------|----------|
| `index.html` | หน้าหลัก แสดงร้านค้าทั้งหมด |
| `admin.html` | หน้าจัดการเพิ่ม/แก้ไข/ลบร้านค้า |
| `style.css` | สไตล์ทั้งหมด |
| `app.js` | ตรรกะและจัดการข้อมูล |

## วิธีใช้งาน

1. เปิดไฟล์ `index.html` ด้วยเบราว์เซอร์ (ดับเบิลคลิก หรือลากเข้าเบราว์เซอร์)
2. คลิกปุ่ม **⚙️ จัดการ** ที่มุมขวาบน เพื่อไปหน้า Admin
3. ในหน้า Admin สามารถ:
   - เพิ่มร้านค้าใหม่ (ชื่อ, ไอคอน/Emoji หรือ URL รูป, ลิงก์, รายละเอียด)
   - แก้ไขร้านค้าที่มีอยู่
   - ลบร้านค้า
   - ล้างข้อมูลทั้งหมด

## ข้อมูลตัวอย่างเริ่มต้น

ระบบจะใส่ร้านค้าตัวอย่าง 4 ร้านให้อัตโนมัติเมื่อเปิดครั้งแรก  
คุณสามารถลบหรือแก้ไขได้ตามต้องการ

## หมายเหตุสำคัญ

- ข้อมูลร้านค้าถูกเก็บใน **localStorage** ของเบราว์เซอร์  
  → ถ้าเปลี่ยนเบราว์เซอร์ / เครื่อง / ล้างแคช ข้อมูลจะหาย
- ถ้าต้องการใช้งานจริงบนเซิร์ฟเวอร์ (หลายคนใช้ร่วมกัน) แนะนำให้ต่อกับฐานข้อมูลหรือ Backend ในภายหลัง
- ลิงก์สามารถใส่ได้หลายแบบ เช่น:
  - Line OA: `https://line.me/ti/p/...`
  - Facebook: `https://facebook.com/...`
  - เว็บไซต์: `https://...`
  - โทรศัพท์: `tel:08xxxxxxxx`

## การปรับแต่งเพิ่มเติม

- เปลี่ยนสีหลักได้ที่ตัวแปร CSS ในไฟล์ `style.css` (`:root`)
- ลบร้านตัวอย่าง: ไปที่หน้า Admin → กด "ล้างข้อมูลทั้งหมด" แล้วเพิ่มร้านจริงของคุณ
